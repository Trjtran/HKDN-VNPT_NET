# HKDN UTH – VNPT NET

## Giới thiệu

Repository lưu trữ tài liệu, mã nguồn và sản phẩm được thực hiện trong chương trình Học kỳ doanh nghiệp giữa Trường Đại học Giao thông vận tải TP. Hồ Chí Minh (UTH) và VNPT NET.

## Mục đích

- Lưu trữ mã nguồn và tài liệu của các đề tài.
- Quản lý quá trình phát triển và cập nhật sản phẩm.
- Hỗ trợ các thành viên phối hợp làm việc thông qua Git và GitHub.
- Lưu trữ kết quả thực hiện phục vụ báo cáo và nghiệm thu.
